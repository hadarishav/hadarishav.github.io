# Rishav Hada — personal website

A dependency-free personal website built for GitHub Pages.

## Preview locally

From the `website` directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

Create a public repository named `hadarishav.github.io`, add these files to its
default branch, and enable GitHub Pages from the repository root. The site will
be available at `https://hadarishav.github.io`.
